# DATA-ANALYTICS-PROJECT---Customer_Behavior_Analysis
Customer Behavior Analysis
An end-to-end data analytics project exploring retail customer shopping
behavior using Python, MySQL, and Power BI. The goal is to
understand purchasing patterns, product performance, customer segments,
discounts, and subscription behavior, then turn the findings into
insights that can support better business decisions.
Project Overview
Retail businesses collect customer and transaction data, but raw data is
not immediately useful for decision-making. This project follows a
practical analytics workflow: inspect and clean the dataset with Python,
store the prepared data in MySQL, answer business questions with SQL,
and present insights through an interactive Power BI dashboard.
Dataset
- Records: 3,900 customer shopping records
- Original columns: 18
- File: customer_shopping_behavior_dataset.csv
- Key fields: customer ID, age, gender, item purchased, category,
  purchase amount, location, size, color, season, review rating,
  subscription status, shipping type, discount applied, previous
  purchases, payment method, and purchase frequency.
The dataset contains 37 missing values in Review Rating. The notebook
fills missing ratings using the median review rating within each product
category.

Project Workflow
1. Load the dataset
   Import the CSV file into a Pandas DataFrame.
2. Explore the data (EDA)
   Review the dataset structure, data types, descriptive statistics,
   and missing values.
3. Clean and prepare the data
   - Fill missing Review Rating values using the median rating
     within each category.
   - Convert column names to lowercase and replace spaces with
     underscores.
   - Rename purchase_amount_(usd) to purchase_amount.
   - Create an age_group feature using age quartiles, labelled
     Young Adult, Adult, Middle-aged, and Senior.
   - Map purchase-frequency categories to an approximate number of
     days in purchase_frequency_days.
   - Compare discount_applied with promo_code_used and remove the
     duplicate promo_code_used field from the prepared DataFrame.
4. Load data into MySQL
   Connect to the customer_behavior database and write the prepared
   DataFrame to the customer_shopping_behavior table.
5. Run SQL analysis
   Use SQL queries to explore revenue by gender, discounted purchases
   above the average purchase amount, and products with the highest
   average review ratings. The SQL file currently contains these three
   analysis queries.
6. Build the Power BI dashboard
   Connect Power BI to MySQL and use the prepared customer shopping
   table to create visual summaries of customer and purchasing
   behavior.
7. Communicate findings
   Summarize the analysis and dashboard insights in a project report
   and presentation as these deliverables are completed.
SQL Business Questions
The current SQL script addresses these questions:
- What is the total revenue generated by male and female customers?
- Which customers used a discount but still spent at least the average
  purchase amount?
- Which five products have the highest average review rating?

How to Run the Project
1. Clone the repository
git clone https://github.com/<your-username>/Customer_Behavior_Analysis.git
cd Customer_Behavior_Analysis
2. Install Python dependencies
pip install pandas sqlalchemy pymysql jupyter
3. Start Jupyter Notebook
jupyter notebook
Open customer_behavior_analysis.ipynb and run the notebook cells in
order. Make sure the dataset CSV is in the same working directory as the
notebook, or update the file path in the CSV-loading cell.
4. Configure MySQL
Create the database:
CREATE DATABASE customer_behavior;
Update the notebook's connection configuration to use your own MySQL
username, password, host, and port. Do not hard-code or commit
passwords. Use environment variables or another secure credential
method.

The notebook writes the cleaned data to:
- Database: customer_behavior
- Table: customer_shopping_behavior
5. Run the SQL queries
Open customer_behavior_sql_queries.sql in MySQL Workbench (or another
MySQL client), connect to your MySQL server, and execute the queries
after the table has been created.
6. Open the Power BI dashboard
Open customer_behaviour_dashboard.pbix in Power BI Desktop. If
prompted, configure the MySQL connection using your own database
credentials.
